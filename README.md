# VectorFlow Support AI

An AI-powered customer support system using Pinecone vector database, Gemini embeddings, and Groq Llama models for semantic search and intelligent chatbot responses.

---

## 🚀 Project Overview

VectorFlow Support AI is a prototype AI customer support platform designed to demonstrate how modern AI technologies like vector databases, semantic search, and large language models can be integrated into a customer assistance system.

The project includes:
- Modern chatbot frontend UI
- Semantic search architecture
- AI workflow design
- Vector database integration concepts
- Intelligent response generation flow

---

## 🧠 How the System Works

1. User asks a question through the chatbot interface.
2. The query is converted into vector embeddings using Gemini AI.
3. Pinecone performs semantic similarity search.
4. Relevant FAQs are retrieved from the vector database.
5. Groq-hosted Llama models generate human-like responses.
6. The response is displayed back to the user.

---

## 🏗️ System Architecture

User → Website → Embeddings → Pinecone → Llama AI → Response
